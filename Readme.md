# 🇧🇩 Bangladesh 2.0

**Bangladesh 2.0** is a simple front-end web project that presents the vision, ideas, and challenges of a modern and innovative Bangladesh.  
This project is built using **HTML, CSS, and JavaScript** and deployed on **GitHub Pages**.

🔗 **Live Demo:**  
https://shaharearhossainjony.github.io/Bangladesh-2.0/

---

## 📌 Project Overview

The goal of *Bangladesh 2.0* is to visually represent the concept of a future-ready Bangladesh by focusing on:

- Innovation  
- Digital transformation  
- Sustainability  
- Development vision  
- Future challenges  

It is a static website suitable for learning and showcasing front-end development skills.

---

## 🛠️ Technologies Used

- **HTML5** – Structure and semantic markup  
- **CSS3** – Styling and responsive layout  
- **JavaScript (ES6)** – Basic interactivity  
- **GitHub Pages** – Hosting and deployment
